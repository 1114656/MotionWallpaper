## 实际视频转换

`scripts/test-video-pipeline.ps1` 的四种两秒素材全部通过：

| 输入 | 输出与验证 |
| --- | --- |
| 10-bit SDR v210 MOV | H.264、8-bit yuv420p、BT.709、limited range |
| PQ v210 MOV | HDR 转 SDR；目标规格和完整解码通过 |
| HLG v210 MOV | HDR 转 SDR；目标规格和完整解码通过 |
| 90° DisplayMatrix MOV | 编码尺寸 640×360 转为 360×640，不残留旋转元数据 |

四例均检查帧率、时长、完整 FFmpeg 解码、源 SHA-256 不变和非全黑/全白亮度；转码预检还运行独立 Windows Media Foundation 首帧解码。亮度检查不能代替 HDR 色调映射的视觉认证。

用户实际 4K、约 239.76 FPS HEVC Main10 MOV 的四秒片段，通过真实转码 API 生成 1920×1080、60 FPS H.264 SDR，完整解码通过。当前驱动的 NVENC API 不满足随包工具要求，实测使用软件编码回退；不声称 NVENC 硬件编码成功。
