# Windows 兼容性第一批修复

日期：2026-09-22。对应同日审计报告中获准先处理的环境准入、显卡探测隔离、候选回退、失败记录、会话状态和安装冲突；三档画质规则保持不变。

## 实现范围

- 工程、安装器和 App 启动基线统一为 Windows 10 22H2 / build 19045。App 在读取和改写配置前检查系统媒体组件、架构、数据目录权限及其他安装位置的运行实例。Windows N 缺少媒体功能时给出系统可选功能指引；Windows 11 ARM64 的 x64 模拟路径明确提示尚未实机验证。
- App 在后台线程启动或连接同目录 Agent，最多等待 10 秒，以仍存活的进程、进程 ID 和启动之后写出的 runtime 作为握手依据。创建失败、提前退出和超时分别展示并写入 `Config/app-startup.log`。
- GPU 清单和逐卡解码能力检查移到可结束的子进程。Agent 读取异步状态；清单超时 10 秒，每张候选卡探测超时 12 秒。候选卡失败后继续尝试后续卡；实际 Renderer 首帧失败也按媒体路径和适配器排除当前路线。
- 持久转码失败绑定源文件身份、目标规格、显卡与驱动信息及工具文件指纹。环境改变后旧失败不再永久阻止生成；用户主动暂停、取消和禁止生成仍保留。GPU 清单后台约每 60 秒重取，检测到环境变化才重置旧播放失败记录，并非实时驱动切换保证。
- 会话连接与锁定分别保存；重连和连接状态轮询不再等价于解锁。交互会话使用 `GUID_SESSION_DISPLAY_STATUS`；无人值守的自动唤醒不会直接把显示器状态改成开启。
- Renderer 错误保留具体操作与 HRESULT / 进程退出码，经 runtime 传到原画失败详情，并按变化写入 Agent 日志。旧版 runtime 缺少新增字段仍可读取。
- 安装前检查媒体组件和数据目录布局。已安装版本改目录升级会明确拒绝；卸载仅停止完整路径属于本安装的进程，仅删除指向本安装目录的启动项。没有隐式迁移既有媒体库。

## 验证记录

安装器在隔离目录完成编译和完整冒烟测试，包括中文与空格路径、缺媒体组件注入、Config 被文件占据、改目录升级拒绝、其他目录同名进程/启动项保护，以及原有迁移中断和恢复用例。没有卸载用户的 `<安装目录>` 安装。

启动测试使用独立临时进程覆盖提前退出、过期 runtime、超时、取消、有效握手、跨目录冲突与创建失败。锁定/重连/自动唤醒通过事件回放验证，没有锁定或挂起当前电脑。

最终 `scripts/build-native.ps1` 完成：102 项原生测试全部通过，编译 0 警告、0 错误，发布目录已更新。GPU 测试包括真实子进程超时/取消、租约释放、逐卡失败接替、保留重负载 DXGI 排序，以及原画首帧失败先尝试其他卡、播放后故障不误判为启动能力失败。管道测试覆盖退出早于读取线程调度时仍保留错误，以及遗留写端不阻塞退出。

## 保留边界

本批不把所有 Windows、显卡或驱动组合宣称为已认证。最低 Windows 10、Windows N 真机、Intel/AMD/多 GPU 和驱动升级仍须在对应环境验收。当前机器的检查不能替代这些组合。

CPU 解码与物理 GPU 呈现分离、不同刷新率屏幕独立调度已在后续[第二批修复](WINDOWS_COMPATIBILITY_PHASE2_2026-09-22.md)中实施。完整硬件矩阵、长期保存固定 FFmpeg 构建制品，以及 Dolby Vision 等特殊色彩输入仍需后续处理。本页安装包哈希与部署记录对应第一批历史产物，第二批记录以其验收报告为准。本次未向远端发布制品、提交或推送代码。
