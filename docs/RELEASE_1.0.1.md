# MotionWallpaper 1.0.1 正式版

日期：2026-10-15。本次更新壁纸管理界面、自适应视频画质和暂停恢复机制。

## 主要更新

- 壁纸库改为紧凑缩略图网格，右侧集中预览、显示器选择和应用操作；屏幕、任务、设置、存储各自独立，设置页支持宽屏双栏和窄屏单栏。
- 统一圆角界面，更新品牌标志和渐变字标；搜索、筛选、排序、导入位于同一行。分组支持拖动与右键管理，导入时可自定义壁纸名称。
- 托盘暂停/恢复与“活动时播放”共享状态。暂停立即停止解码，短暂停保留快速恢复窗口，超时释放资源；恢复时保持静帧直至定位就绪，减少片头闪帧与卡顿。
- 全屏覆盖按屏幕独立暂停。同一显卡、同一视频、同步播放时共享解码，各屏独立呈现。
- 平衡副本按显示器分辨率和刷新率生成，根据源规格、硬编及实际硬解预检选择 10-bit 或 8-bit；广色域与 HDR 按各屏能力分别保留或转换。源 8-bit 不升为 10-bit，不插帧、不放大低规格源。
- 节能副本保持最高 1080p、H.264 / 8-bit / BT.709 SDR。无需颜色转换的输入优先 GPU 缩放，保留 CPU 颜色处理及硬件编码回退；任务页提供单视频兼容生成入口。
- 新配置默认平衡，导入视频后自动准备性能副本；失败、取消、停止和删除状态明确显示，不再反复自动重建。
- 任务页勾选源文件后删除整张壁纸，源文件、全部副本、封面和元数据一起移入回收站；仅勾选副本时仍只清理对应档位。
- 修复 FFmpeg 上游每日包过期导致的构建失败，固定到保留两年的 2026-09 月末 LGPL 共享构建，继续严格核对 SHA-256。

完整记录见 [更新日志](../CHANGELOG.md)，画质规则见 [自适应视频画质](ADAPTIVE_VIDEO_COLOR.md)。

## 安装与升级

下载本页附件中的 Windows x64 安装包（`.exe`）或便携包（`.zip`），各自附有 `.sha256` 校验文件。产品版本为 `1.0.1`，Windows 文件版本为 `1.0.1.65535`。

已有安装版请退出程序后，使用原目录覆盖安装。**不要先卸载**：卸载会清除安装目录内的默认媒体库、配置和日志；安装目录外的媒体库与旧数据回滚副本保留。便携升级请保留 `Wallpapers` 和 `Config`，建议先在程序内备份媒体库。旧版中已删除源文件的壁纸仍可播放已有副本，但无法重新生成。发布包不包含个人媒体库、配置或日志。

最低目标为 Windows 10 22H2（19045）或 Windows 11 x64，需可用的 Windows Media Foundation；Windows N 需 Media Feature Pack。程序随附 Windows App SDK、VC++ Runtime 和 FFmpeg。硬件编码与解码能力分别探测，驱动要求见 [视频运行环境](VIDEO_ENVIRONMENT.md)。

## 验证范围与限制

本次本地 Release x64 构建及 132 项原生回归测试全部通过，三个程序的产品版本与文件版本均已核对。发布流程在干净的 GitHub Actions 环境再次构建与测试，检查便携包内容、安装器及隔离安装/卸载，并生成附件校验和。本地暂停恢复验证覆盖系统 Media Foundation 与内置解码路径；历史色彩、转换样片的设备与测试范围见 [自适应视频画质](ADAPTIVE_VIDEO_COLOR.md)。

- 当前安装包未代码签名，Windows SmartScreen 可能提示。
- Intel、AMD、混合显卡、多代驱动、干净系统、真实 HDR 面板及长期运行尚未完成完整实机矩阵验证；正式版不代表所有硬件组合均已认证。
- 依赖及随附工具的完整许可证复核、适用地区 H.264 许可判断、最终附件的 SmartScreen 与杀毒软件误报验证尚未完成。
- HDR/广色域能否保留取决于源视频、驱动和 Windows 当前高级颜色状态。检测或输出路径不支持时回退 SDR，不支持 Dolby Vision 直通。
- “颜色异常？兼容生成”是手动恢复入口，并不表示程序已经检测出偏色；自动预检不能识别所有显示器上的视觉色差。
- 原画播放仍可能有较高解码与显存开销；高刷新率节能副本也不保证最低功耗。

第三方组件适用各自许可证，见 [第三方软件声明](../THIRD_PARTY_NOTICES.md)。
