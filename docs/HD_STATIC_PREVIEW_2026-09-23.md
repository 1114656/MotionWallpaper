# 高清静态预览

日期：2026-09-23。

## 问题与行为

桌面在等待性能副本、或原画播放失败后，原先直接显示媒体目录内的 `poster.png`。这张 480×270 的列表封面被放大到 3840×2160，导致静态画面明显模糊。

Agent 现在使用独立的按需高清预览服务。已有壁纸无需重新导入：首次需要静态预览时先显示小封面，同时后台提取原视频第一帧；完成后按新的图片路径自动切换。原文件已被删除时，可以使用保留的性能副本提取。缩略图及媒体元数据不变。

- 预览保持源比例和 MOV 旋转方向，不放大低分辨率源。横屏最高 3840×2160，竖屏最高 2160×3840，超宽画面按比例缩小。
- 输出 RGB24 / sRGB PNG。SDR 保留正确的传递函数；PQ/HLG 使用现有线性光色调映射，再编码成 sRGB，不沿用 HDR 元数据。不修改原视频。
- ffprobe 最多 10 秒，提取子进程最多 30 秒；提取使用两个解码线程、一个滤镜线程，一次仅处理一个任务。最多排队 8 个不同源，相同源去重，失败后 5 分钟再试。
- `Config/DesktopPreviews` 只缓存 PNG，不在 Agent 常驻解码后的像素。清理目标为 128 MB，按文件时间移除未使用的旧图。正在显示的文件通过 Windows 句柄租约保护，因此活动图片可以暂时超过清理目标。
- 缓存身份包含源文件的卷序列号、文件 ID、大小和修改时间；源变化后重新生成。先验证临时 PNG，再原子发布。超过 5 分钟的遗留临时文件在下一次成功生成时清理。
- 外置媒体继续使用稳定卷路径与媒体库身份租约；性能副本提取期间也持有副本租约。取消、退出和恢复原视频播放时可终止提取并等待子进程退出。

高清图用于等待副本和播放失败的静态回退。正常视频暂停仍保留当前已呈现的帧。
