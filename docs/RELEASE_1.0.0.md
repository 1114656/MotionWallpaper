# MotionWallpaper 1.0.0 正式版

日期：2026-09-23。1.0 系列首个正式版本，以用户确认的 0.2.1 功能为基线。本次统一版本资源、发布说明和正式交付物。

## 核心功能

- 导入 MOV、MP4 等视频及静态图片，管理壁纸分组、收藏、标签和备份。
- 原画直接播放源文件；Windows 缺少解码器时可回退到随包 HEVC/H.264 解码器，优先 GPU 硬解。
- 平衡副本按显示器物理分辨率与刷新率生成，节能副本最高 1080p；均不超过源帧率、不插帧、不放大低规格源。
- 同一显卡、同一视频、同步播放的屏幕共享解码，各屏独立呈现。
- 按需生成最高 4K 的高清静态画面；转码优先完成，日常播放保留暂停和节能策略。
- 支持闲置动态屏保、全屏暂停、锁屏停止、场景切换、随机轮换和系统托盘控制。

## 环境要求

- Windows 10 22H2（19045）或 Windows 11，x64。
- 基础 Windows Media Foundation 可用；Windows N 需要 Media Feature Pack。
- 当前用户可写的安装目录或便携目录。
- 显卡能力按视频编码、profile、分辨率和驱动实际探测，不强制指定显卡型号。软件兼容存在预算，不能保证所有设备流畅播放 4K 高帧率原片。

程序随附 Windows App SDK、VC++ Runtime 和固定版本 FFmpeg。硬件编码与硬件解码是不同能力，具体驱动要求见 [视频运行环境](VIDEO_ENVIRONMENT.md)。

## 安装和升级

- 安装包：`MotionWallpaper-正式版-v1.0.0-Windows-x64-安装包.exe`。
- 便携包：`MotionWallpaper-正式版-v1.0.0-Windows-x64-便携版.zip`。
- 两者均附 `.sha256` 校验文件；产品版本为 `1.0.0`，Windows 文件版本为 `1.0.0.65535`。

已有安装版请退出程序后，使用原安装目录覆盖安装。**不要先卸载**：卸载会清除安装目录内的默认媒体库、设置和日志。便携升级保留 `Wallpapers` 与 `Config`，建议先通过程序备份媒体库。

## 验证与已知限制

功能基线已通过 119 项原生回归、6 组色彩对照及隔离安装测试；具体证据见 [0.2.1 验证记录](RELEASE_0.2.1_LOCAL_VALIDATION.md)。GTX 1070 / 582.66 的双屏实测中，4K HEVC Main10 原片首帧约 0.52 秒，两段观测中的呈现进度约 60 帧/秒。版本变更后的构建、安装检查和交付物校验记录见 [1.0.0 构建验证](RELEASE_1.0.0_VALIDATION.md)。

- 当前安装包未代码签名，Windows SmartScreen 可能提示。
- 内置播放输出 sRGB SDR；PQ/HLG 经显示转换，不支持 HDR 直通或 Dolby Vision。
- Intel、AMD、混合显卡、多代驱动、干净 Windows 系统和长时间运行尚未完成完整实机验证。正式版名称不代表这些组合均已认证。
- 两块显示器可能都显示 `Generic PnP Monitor`，这是系统提供的通用名称。运行状态按屏幕列出，共享解码仍可生效；下方显示器布局提供编号和主屏标识。
- 高分辨率原片仍有解码、显存和内存开销，日常省电建议使用性能副本。
